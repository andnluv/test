# 태번 도구함 v0.3.10 — 한글화 모듈 확장

## 이번 버전 신규 기능

- **프롬프트 토글 이름 자동 한글화**: SillyTavern 공식 프롬프트 매니저의 표시 이름만 변경합니다. 프롬프트 원문, 식별자, 순서, 활성화 상태, 모델 전송 데이터는 수정하지 않습니다.
- **기본 번역 사전 없음**: 한국어 번역 결과는 사용자가 선택한 **저장 연결 프로필**에 요청합니다.
- **RP 연결 유지**: 공식 `ConnectionManagerRequestService.sendRequest()`를 통해 별도로 번역을 요청합니다. 현재 선택된 RP 프로필을 전환하지 않습니다.
- **자동 번역/수동 번역**: 새 프롬프트 이름이 나타나면 자동 요청하거나 '현재 토글 번역' 버튼을 누릅니다. 연결 프로필이 선택되지 않았다면 번역 요청하지 않습니다.
- **번역 캐시**: 이름별로 한국어 번역을 저장하고 수정·삭제·전체 초기화할 수 있습니다. 한글화 OFF 시 원문 표시로 복귀합니다.
- **기존 사유 제목**: `사유 · 1분` 및 시간 표시 옵션을 그대로 유지합니다.
- **7개 모듈 골격**: 디자인/한글화 활성화, 번역/QR/조회/대필/모바일 최적화는 후속 개발까지 사용 불가 상태로 표시합니다.

## 사용 방법

1. GitHub 저장소 최상위에 이 ZIP 내부 파일을 그대로 업로드합니다.
2. SillyTavern 확장을 업데이트하고 새로고침합니다.
3. 태번 도구함 → **한글화 · 추론 제목 / 토글 이름**을 펼칩니다.
4. '번역용 연결 프로필'에서 **저장된 연결 프로필을 선택**합니다.
5. 프롬프트 매니저를 열면 이름을 번역하고, 모델 응답으로 받은 번역을 화면에 표시합니다.
6. 오류가 나거나 번역이 적절하지 않으면 '번역 결과 수정 및 캐시'에서 수정하거나 삭제합니다.

**주의:** 모델 번역 요청에 사용량·비용이 발생할 수 있습니다. 잘못된 번역은 캐시에서 바로잡을 수 있습니다. 처음에는 프롬프트 몇 개로 확인하세요.

**지원 환경:** 실리태번에 내장된 Connection Manager가 활성화되어 있어야 합니다. 일부 연결 프로필은 API 지원 상태에 따라 제외될 수 있습니다. 저장 연결 프로필이 없는 경우 원문을 유지합니다.

**개인정보:** 프롬프트 *이름*만 번역 서비스로 전달합니다. 프롬프트 본문, 채팅 기록, 캐릭터 설명은 보내지 않습니다.

**범위:** 이번 버전은 공식 Chat Completion 프롬프트 매니저의 토글명에 한정합니다. 기타 타사 프롬프트 UI 및 전체 메뉴 한글화는 다음 단계입니다.

**검증:** 로컬 자동 테스트 및 JS 문법/ZIP 검사를 수행했습니다. 실제 사용자 SillyTavern 화면에서의 동작은 아직 확인하지 않았습니다.

## v0.2.5: Porcelain (청화백자 + 백자음각)

네 번째 완성형 테마 **Porcelain**을 추가했습니다. 순백색 본문과 청화 장식선, 음각형 패널·모달·입력창 디자인을 사용합니다.

테마 선택 후 **테마 컬러 변경 · 컬러칩**에서 다음 세 가지를 선택할 수 있습니다.

- **클래식**: 흰 백자와 정통 코발트블루 문양, 청회색 음각선
- **로얄**: 진한 청화 블루와 선명한 경계선
- **트림**: 흰 백자와 코발트블루에 절제된 금빛 테두리

컬러칩은 배경·패널·본문·구분선·메시지색을 묶어 적용하며, 사용자 편집 컬러는 현재 테마별로 별도 저장됩니다. 테마 전환 시 지문·대사 글꼴과 타이포그래피 설정은 유지됩니다. 아이콘 스타일 및 색상은 독립 설정입니다.

원작 도자기 이미지를 복제하거나 외부 미술 자산을 포함하지 않았습니다. 장식은 순수 CSS로 작성되었습니다. 실제 SillyTavern 및 다른 확장과의 시각적 호환성은 사용자 환경에서 확인이 필요합니다.


## v0.3.7 프롬프트 토글 표시 오류 수정

## v0.3.7 상단 메뉴 아이콘 대비 보정

상단 메뉴 아이콘의 색이 밝은 테마에서 흰색 또는 투명하게 표시되는 문제를 예방하도록 명시적 잉크색을 지정했습니다. 기존 버튼 클릭 이벤트와 사용자가 선택한 아이콘 색상 모드는 유지합니다. 실제 테마 조합에서는 추가 확인이 필요합니다.

## v0.3.7 오류 수정
- 프롬프트 이름은 공식 SillyTavern `data-pm-name`과 이름 링크의 텍스트만 수정하며, 추가 span을 넣지 않습니다. 프롬프트 원본은 보존됩니다.
- 번역은 8개씩 묶어 JSON 배열로 요청합니다. 보이는 프롬프트를 전부 재수집하고, 실패한 항목 수를 표시합니다. 미번역 항목은 **현재 토글 번역** 버튼으로 재시도할 수 있습니다.
- Porcelain 상단 메뉴의 레이아웃을 움직일 수 있는 border-bottom을 제거하고 inset 선으로 대체했습니다.
- 실제 SillyTavern 환경에서는 추가 검증이 필요합니다.


## v0.3.7 — 프롬프트 표시 및 본문 렌더링 수정
- 프롬프트 이름 안의 중첩 요소를 삭제하거나 건너뛰지 않고, 기존 텍스트 노드만 교체합니다. 번역 캐시와 원본 프리셋은 유지합니다.
- 한글화 OFF 시 기존 텍스트 노드를 복원합니다.
- 확장 테마 활성화 시 기본 테마에서 상속된 텍스트 테두리·그림자·흐림 효과를 제한된 범위에서 제거합니다.
- 참고용으로 제공된 WHITE 테마 JSON은 blur_strength=0, shadow_width=0, noShadows=true로 설정되어 있음을 확인했습니다. 해당 테마의 SVG, 장식, CSS 코드를 확장에 복제하지 않았습니다.
- 기존 실리태번 테마의 JSON이나 채팅 저장 데이터는 수정하지 않습니다.
