# 태번 도구함 v0.2.0 — 완성형 테마 3종

기존 v0.1.x의 단순 색상 덧씌우기 방식 대신 Paper / Nocturne / Studio 각각의 완성형 UI 테마를 제공합니다. 다른 회사/확장 프로젝트의 코드를 포함하지 않습니다.

## 테마
- **Paper**: 소설형 종이 바탕, 명조 본문, AI 메시지에는 카드 박스 대신 문단/구분선. 사용자 메시지는 연한 카드.
- **Nocturne**: 청흑색 저자극 팔레트, 낮은 광택의 카드, 메시지 왼쪽 은빛 포인트, 고딕 본문.
- **Studio**: 세이지/회녹색, 부드러운 카드, 정보 분리형 레이아웃, 고딕 본문.

모든 테마는 본문, 배경, 메뉴/패널, 대화 메시지, 입력창, 버튼/필드, 모바일 레이아웃에 색상 및 구성 규칙을 제공합니다. 완전한 UI 교체는 아니며 SillyTavern 기본 UI의 DOM을 그대로 사용합니다. 외부 확장의 자체 UI까지 일괄 스킨을 씌우는 것은 보장하지 않습니다.

## 설치 (GitHub)
1. 이 배포 ZIP에서 `tavern-toolkit-v0.2.0` 폴더 **안의 내용**을 GitHub 저장소의 최상위에 업로드합니다. `manifest.json`, `index.js`, `design.js`, `style.css`, `fonts/`가 저장소 루트에 있어야 합니다.
2. 이미 설치한 실리태번 확장은 확장 관리에서 업데이트하고 새로고침합니다.
3. `확장 설정 > 태번 도구함`을 펼치고 `완성형 테마 및 가독성 설정`을 펼칩니다.
4. 원하는 테마를 적용합니다. 설정값은 즉시 반영됩니다.

`design.js`를 `modules/design.js`로 옮기면 import 경로도 함께 바꿔야 합니다.

## 안전성 및 제한
- 기존 SillyTavern 테마 설정값/프리셋/대화 데이터를 직접 수정하지 않습니다. 해제하면 테마 CSS 적용 스위치를 내려 기존 테마로 돌아갑니다.
- v0.1.x 디자인 설정은 읽을 수 있습니다. `midnight`는 `nocturne`, `sage`는 `studio`로 매핑합니다. 사용자가 기존에 지정한 일부 색상은 유지될 수 있어 `현재 테마 초기화`로 초기화할 수 있습니다.
- 폰트: 프로젝트 내장 나눔고딕/나눔바른고딕/나눔명조 (폰트 OFL 안내는 `fonts/OFL-1.1.txt`). 인터넷 연결 불필요.
- 한글화/번역/QR/조회는 **아직 구현 전**입니다. UI 스위치는 준비되어 있지만 활성화 불가능합니다.
- 타사 테마/확장과 CSS 충돌이 여전히 가능하며, 모바일 환경/모든 SillyTavern 버전에서의 실기기 검증은 진행되지 않았습니다.
- 완성형 테마 사용 중 다른 테마의 일부 고유 장식은 가려질 수 있습니다. 기존 테마를 일부 보존하는 독서 모드는 제공하지 않습니다.

## 테스트
`node --check index.js` 및 `node --check design.js`, `node --test design.test.mjs` 로 기본 문법/설정 테스트를 실행할 수 있습니다. 브라우저 실제 화면 검증은 별도로 필요합니다.
